## 卡 A：桌面组件（发布门槛，约 10 分钟）

本轮组件已按 macOS 26 要求沙盒化（此前不入画廊的根因），数据在共享容器，与主应用同库。

1. 在桌面空白处**右键 →「编辑组件…」**（或通知中心 → 底部「编辑组件」），搜索 **"Draft Zero"**（注意有空格），添加**中号**组件到桌面。
   - 如果画廊里仍搜不到：先注销并重新登录（重启组件服务）再搜一次，并把这一步记录为发现。
2. **空状态**：当前日常库还没有项目，组件此时应显示「还没有项目」引导文案。
3. 在主应用里创建两个测试项目（例如"组件测试甲""组件测试乙"），把"组件测试甲"设为 TODO。等组件刷新后核对主路径：
   - a. 组件显示 **TODO 区**（组件测试甲）与**最近项目区**（组件测试乙）；
   - b. 点 TODO 区的项目行 → 主应用打开该项目档案；
   - c. 点「新建草稿」→ 主应用打开新稿页。
   （此前版本的组件内 ✓/◌ 一键状态按钮已按复核意见移除；状态修改在主应用完成。）
4. 明暗背景：组件分别放亮色与深色壁纸（或切换系统外观），文字应可读。
5. **清理**：删除两个测试项目与测试草稿；确认日常数据与测试前一致。

**判据**：出现在画廊 + 空状态 + 四条主路径 + 明暗可读 → 通过。任何一步失败请截图并记录步骤。

### 原卡 B：减少动态效果（约 5 分钟）

1. 记录当前状态：系统设置 → 辅助功能 → 显示 → 减少动态效果。
2. 打开开关，重启 Draft Zero，终端运行：

   log show --last 5m --predicate 'subsystem == "com.draftzero.app" AND category == "accessibility"'

   应看到 `accessibilityReduceMotion(启动读取) = true`（应用确实读到系统值）。
3. 走一遍主路径：线索台点开/关闭一条线索的证据栏（应淡入或直接出现，无横向位移）→ ⌘N 新建草稿 → ⌘L 添加链接弹层。
4. 关闭开关恢复原状，再跑一次第 2 步命令，应见 `= false`。

**判据**：第 2 步读到 true 且第 3 步无位移依赖 → 通过。

## 卡 C：VoiceOver 主路径 —— **产品所有者裁定首版不测（2026-09-30），发布说明如实标注"未复核"**

<details><summary>原卡内容存档（未来版本补测时使用）</summary>

### 原卡 C：VoiceOver 主路径（约 10 分钟）

1. ⌘F5 开启 VoiceOver（或系统设置 → 辅助功能 → VoiceOver）。
2. 依次听读并记录是否「不用看屏幕也能懂」：
   - VO+左右箭头沿左侧索引走一遍（01 草稿箱 → 06 设置，每项应朗读编号+名称）；
   - VO+空格激活「新草稿」→ 听到「标题」「正文」字段 → 输入两句 → 保存；
   - ⌘2 到线索台 → 逐条听队列（每条应含两稿标题与证据说明）→ 对一条执行「加入项目」→ 弹层内焦点应落在弹层、关闭后回到原处；
   - 打开项目档案 → 状态菜单改为 TODO → 回 TODO 页确认；
   - 打开刚编辑的草稿详情 → 版本来路 → 比较旧版 → 恢复；
   - Escape 返回，确认焦点不丢失。
3. ⌘F5 关闭 VoiceOver。

**判据**：全部步骤朗读可理解、焦点不困死 → 通过；任一步「听不懂」或焦点卡死 → 记录具体步骤。

</details>

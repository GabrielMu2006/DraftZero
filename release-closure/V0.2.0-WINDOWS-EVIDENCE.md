## 2. M0 技术关口（详见 `Windows/evidence/M0-TECHNICAL-GATE.md`）

- token IDs：C# vs Mac 生产引擎 vs Python 参考实现，黄金样本 9/9 完全一致。
- 向量：C# 与 Python fp32 参考逐位一致；对 Mac int8-CoreML 黄金样本余弦 0.947–0.992（量化噪声，根因已证，处置已记录）。
- **冻结 30 份集双指标：recall@5 = 21/21 = 100%，prec@3 = 46/63 = 73.0%（门槛 80%/70%，双达标）**；报告 `Windows/evidence/M0-eval-fp32.json`（含逐篇排名、文件 SHA）。
- PDF 提取（PdfPig，Apache-2.0）与 PDF 应用内预览（Windows.Data.Pdf）已实现；预览实机效果在复核卡待验。

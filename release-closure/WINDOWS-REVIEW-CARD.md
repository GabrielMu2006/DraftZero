# Windows 实机复核卡（V0.2.0 · 产品所有者手工执行）

**目的：** 完成代理按边界无法执行的真实安装 / 升级 / 卸载与界面复核。全程约 20–30 分钟；只需本卡与候选安装器。**遇到崩溃/数据异常请截图并开 Issue，不要重试覆盖数据。**

**你需要：** 一台 Windows 11 24H2+ x64 电脑（即构建用的那台即可）；候选安装器 `DraftZero-Setup-v0.2.0-win-x64.exe`（GitHub Release 资产或 `dist/` 内文件）；如已有 Mac V0.1.0 工作区，另备 Mac V0.2.0 导出的 `.dzarchive`（脱敏版）。

**核对安装器（可选但推荐）：** PowerShell 运行
`Get-FileHash .\DraftZero-Setup-v0.2.0-win-x64.exe -Algorithm SHA256`
应等于 `24a289ef48191d326ed936931958f877a64a433b4be657853e33d30110e37741`。

**没有 Mac 工作区？** 用仓库自带的脱敏演示档案即可完成卡 B-8：
`dist/演示工作区（脱敏）.dzarchive`（或仓库内 `Windows/tests/DraftZero.Core.Tests/Fixtures/migration/sample.dzarchive`，
两者相同；内容为 5 份示例草稿 + 1 份示例 PDF + 1 个项目，无任何真实资料）。

## 卡 A：安装与首启

1. 双击运行安装器。**预期**：SmartScreen 可能提示「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（不要全局关闭保护）。
2. 安装向导为中文；**预期**：无需管理员授权（UAC 不弹出）；完成后开始菜单出现「Draft Zero」与「卸载 Draft Zero」。
3. 启动 Draft Zero。**预期**：窗口约 1180×760，左侧「01 草稿箱…06 设置」索引脊背，浅色纸面（深色系统主题下为夜间档案色）。
4. **缩放复核**：显示设置切 100% 与 150% 各看一次草稿箱与设置页——文字不重叠、按钮不被裁切。
5. **空状态**：草稿箱应显示「新建草稿」与「导入文件/链接」两个入口。
6. **记录**：界面异常、文字乱码、图标缺失等截图。

## 卡 B：功能主路径

1. **新建草稿**：Ctrl+N → 只写正文一句话 →「保存到草稿箱」。**预期**：保存成功并选中该稿。
2. **导入**：拖一个 .md / .txt 进草稿箱（或 Ctrl+O 选择）。**预期**：右上角浮层逐项显示「已导入」；原文件内容不变。
3. **再导同一文件**。**预期**：提示「重复：已有「…」」——不生成重复草稿。
4. **PDF**：拖入一个 PDF。**预期**：详情页出现应用内页预览（可翻页）；扫描版 PDF 显示「无可用于关联的文字」。
5. **项目**：把草稿加入项目（详情页 →「加入项目」），建项目名；项目页切换「成员 / 演化」；把项目状态改为 TODO，左侧 04 页能找到。
6. **编辑与版本**：在草稿里改两处文字，停 60 秒以上或离开页面；「版本（N）」出现记录；点「恢复」旧版——**预期**：恢复成功且历史仍在。
7. **线索台**（02）：有 3 份以上同主题草稿时，**断网**（拔网线/关 Wi-Fi）后等索引完成。**预期**：出现「待审线索」，点开可见双方原文片段与依据；「归入项目」「不相关」「暂缓」可点。DeepSeek 从未开启——**任务管理器确认没有可疑联网**（核心归类完全离线）。
8. **迁移导入**（如备有 .dzarchive）：设置 → 从 Mac 导入工作区 → 选档案。**预期**：进度后显示导入计数；草稿/项目/PDF 可打开；再导一次同档案——**预期**：提示工作区已有内容，拒绝（不做合并）。
9. **深链确认**：浏览器地址栏输入 `draftzero://new-draft?title=测试&content=深链内容`。**预期**：应用内弹「创建草稿」确认框；点「拒绝」后**不**出现新草稿。

## 卡 C：升级与卸载

1. **升级保留数据**：用同一安装器再装一遍（或未来新版本同 AppId）。**预期**：无需卸载直接覆盖；启动后卡 B 里的草稿、项目、版本全在。
2. **卸载保留数据**：开始菜单 →「卸载 Draft Zero」→ 卸载完成。**预期**：安装目录与开始菜单项消失；`%LocalAppData%\DraftZero\` **仍在**（资源管理器核对）。
3. （可选）确认 `%LocalAppData%\DraftZero\secrets.bin` 只在启用过 DeepSeek 后存在；卸载后该文件不随卸载删除（含 Key 时请手动删除）。

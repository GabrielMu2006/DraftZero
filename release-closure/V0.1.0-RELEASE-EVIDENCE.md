## 2. 依赖解析修复（C.1，含供应链处理）

- 复现：全新环境解析在 swift-transformers / swift-argument-parser 报"版本提交哈希与 Package.resolved 不一致"。
- 根因：本机 `Core/.build/repositories` 与 SwiftPM 共享缓存/指纹文件中存在 **2026-09-27 伪造的单提交（"init"）依赖仓库**，旧 Package.resolved 记录的是伪造哈希；上游真实 tag 为 swift-transformers `0.1.14→d42fdae`（现随 `from:` 区间解析为 **0.1.24/f000aa7**）、swift-argument-parser `1.4.0→0fbc884`。
- 内容比对：伪造快照与真实上游 tag 的源码内容 **逐文件一致**（swift-transformers Sources+Package.swift、swift-argument-parser 全目录 diff 为空），故此前测试与 R-004 证据仍然有效。
- 处置：删除被污染的项目缓存、共享缓存仓库与指纹 JSON；`Package.swift` 改精确锁定（GRDB 7.11.1、swift-transformers 0.1.24）+ 提交真实 `Package.resolved`；`swift test` **71 项 0 失败**（2 项真实网络冒烟按设计跳过）；R-004 冻结双指标复现 **recall@5 21/21、prec@3 47/63**（[R004-post-dependency-fix-run1.json](evidence/R004-post-dependency-fix-run1.json)）。

## 5. 桌面组件（D.1）与无障碍（D.2）现状

- **数据路径**：`dz-eval widget-qa`（与 Widget 源同实现）在隔离库重验：时间线读取 → 两种状态按钮写入 → 时间线翻转，全部通过。
- **组件不入画廊的根因与修复（2026-09-29 深夜）**：产品所有者在系统画廊实搜不到本组件。对照组实证：本机可正常上桌面的第三方组件（API Meter）为"沙盒扩展 + 不沙盒主应用 + ad hoc 签名"；本产品扩展未沙盒，是 WidgetKit 不收录的直接原因。
  - 第一次修复尝试（App Group 容器方案）被 Xcode 构建拒绝：App Group entitlement 要求开发证书签名（ad hoc 不可用，错误见构建日志）。
  - 最终方案：扩展接 `app-sandbox` + `temporary-exception.files.home-relative-path.read-write`（精确授权 `~/Library/Application Support/DraftZero/`，与主应用同库）；Core 经 passwd 解析真实主目录（沙盒内 `~` API 重定向不可用）；应用侧数据位置不变、无迁移。
  - 重构建两次通过（新 ZIP SHA-256 `b139b030…24409`），扩展 entitlements 实测嵌入（codesign -d --entitlements）；/Applications 已重装；主应用启动正常、日常数据可见。
  - 卡 A 判据相应更新：沙盒扩展读不到 /tmp，桌面组件测试直接用真实数据（先空状态，再建两个测试项目验证四路径后删除）；`DZ_WORKSPACE_DIR` 只对不沙盒进程生效，卡 A 期间不得设置。
- **实机进展（2026-09-30）**：最终包装入 /Applications 后，产品所有者在系统画廊实搜到组件并添加到桌面——**画廊收录这一发布门槛达成**；桌面组件成功渲染主应用真实数据（沙盒扩展经 temporary-exception 读共享目录验证通过），「新建草稿」入口实测可用。组件内两种状态按钮实机交互不稳定，按产品所有者裁定移除，组件改为项目一览 + 点击直达主应用对应项目（ACCEPTANCE.md 已知偏差 4）。
- **菜单重设计引发的一次崩溃（已修复，留档）**：6 处原生 Menu 换自绘菜单后，首版用 `.popover` 承载，点击即崩（两份 .ips：IOGPU Metal 遥测在瞬态窗口创建路径对 CFString doesNotRecognizeSelector → SIGABRT，系统层缺陷、触发条件明确）。修复：菜单改为主窗口内部浮层（GeometryReader 上报按钮窗口坐标 + 顶层统一渲染 + 点击空白关闭），不再创建瞬态窗口；随后按复核反馈把水平定位改为按钮右缘对齐。产品所有者实测确认不再崩溃，对齐待其复核。
- **剩余待真人项**：6 处菜单样式与对齐复核、卡 A 新形态复核（项目行直达/空状态/明暗）、卡 B（减少动态效果）、卡 C（VoiceOver）——复核卡已按新组件形态更新 [FINAL-CHECKLIST-v0.1.0.md](FINAL-CHECKLIST-v0.1.0.md)。

- **Gatekeeper**：`spctl` assessments enabled、本包 rejected；带 quarantine 的副本启动后被系统异步评估终止（未签名的预期行为）。官方「隐私与安全性 → 仍要打开」流程已写入发布说明；真实浏览器下载路径的提示体验列入复核卡顺带项。
